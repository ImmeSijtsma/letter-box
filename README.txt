LETTER BOX 💌
================
Upload this whole folder to GitHub.

GitHub Pages:
1. Repository -> Add file -> Upload files.
2. Upload index.html, manifest.json, sw.js and the icons folder.
3. Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save and wait for the Pages URL.

iPhone:
Open the GitHub Pages website in Safari -> Share -> Add to Home Screen.

Data is stored locally in the browser. Use Backup in Statistics to export your letters.
Note: lots of large photos can fill browser storage; 20 photos is supported per letter, but smaller/compressed photos work better.
